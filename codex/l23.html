非交互与 app-server

pi 有四种运行模式：交互、print/JSON、RPC 与 SDK（第 18 课）。Codex 的对应物是：codex exec（脚本与 CI）、codex app-server（JSON-RPC，供 IDE 插件与桌面应用使用），而 TUI 与 exec 本身都是 app-server 的进程内客户端——exec/src/lib.rs 直接使用 InProcessAppServerClient，TUI 通过 app_server_session.rs 说同一套协议。所以 app-server 协议就是 Codex 的“SDK”。本课把这几种入口各用一次。约 45 分钟。

# 剧本：请求带 text.format（--output-schema）时回 JSON，否则先 ls 再回答
import json
def reply(n, body):
    fmt = body.get("text", {}).get("format")
    if fmt:
        print(f"[mock] text.format.type={fmt['type']} name={fmt.get('name')} strict={fmt.get('strict')}", flush=True)
        return [msg(json.dumps({"files": 0, "ok": True}))]
    if n == 1: return [msg("我先看看"), call("exec_command", {"cmd": "ls"}, "c1")]
    return [msg("空目录")]
EOF
02
app-server 通知计数。
cat > codex/scratch/l23.py <<'EOF'
# app-server：一次回合中客户端收到哪些通知（按方法名计数，保持首次出现的顺序）
import os, sys, collections; sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from apc import AppServer, text
a = AppServer(cwd=os.getcwd()); tid = a.start(os.getcwd())
a.request("turn/start", {"threadId": tid, "input": text("看看目录")})
seen = collections.Counter()
a.wait("turn/completed", show=lambda m: seen.update([m["method"]]))
for k, v in seen.items(): print(f"  {v:3d}  {k}")
a.close()
EOF

小结
记住这几点


  1. exec 的输出：默认是给人看的文本；--json 输出 JSONL，事件定义在 exec/src/exec_events.rs：thread.started、turn.started/completed/failed、item.started/updated/completed（agent_message、command_execution、mcp_tool_call、file_change、todo_list……）。
  2. 结构化答案：--output-schema schema.json 让请求带上 text.format = {type: json_schema, name: "codex_output_schema", strict: true}（codex-api/src/common.rs）；-o 文件 把最后一条助手消息写入文件。
  3. --ephemeral：不写 rollout（实验中文件数不变）；exec resume/fork 见第 15 课。
  4. app-server：stdio（默认）或 --listen 指定的传输上的 JSON-RPC；先 initialize（可声明 experimentalApi）+ initialized，再 thread/start、turn/start。一次带工具调用的回合产生 thread/status、turn/*、item/*、增量、token 用量、限额等通知（实验 4）。
  5. 双向：服务器也会向客户端发请求（审批、用户输入、动态工具调用等，第 13 课用过）。generate-json-schema 显示此提交中客户端请求 106 种、服务器通知 85 种、服务器请求 10 种；generate-ts 生成 TypeScript 类型。
  6. 选择：一次性任务与 CI 用 exec（加 --json/--output-schema）；需要多轮、审批交互、在自己的界面中显示进度时用 app-server。
