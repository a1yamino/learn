斜杠命令

pi 的斜杠命令来自扩展与提示模板（第 16 课）；Codex 的斜杠命令是 TUI 中一个枚举 SlashCommand：枚举顺序就是弹窗顺序，每个命令有描述、是否接受行内参数、任务进行中是否可用等属性，再由 slash_dispatch.rs 分派。有的命令只改界面状态，有的调用 app-server 方法，还有的（如 /init）只是把一段内置提示当作普通用户消息提交。本课在伪终端中驱动真实的 TUI。约 35 分钟。

import fcntl, os, pty, re, select, struct, sys, termios, time

if pid == 0:
    os.environ["TERM"] = "xterm-256color"
    os.execvp("codex", ["codex", "-c", "approval_policy=never"])
fcntl.ioctl(fd, termios.TIOCSWINSZ, struct.pack("HHHH", 40, 110, 0, 0))  # 40 行 × 110 列
buf = b""
def pump(sec):
    global buf
    end = time.time() + sec
    while time.time() < end:
        r, _, _ = select.select([fd], [], [], 0.1)
        if not r: continue
        try: d = os.read(fd, 65536)
        except OSError: return
        buf += d
        if b"\x1b[6n" in d: os.write(fd, b"\x1b[1;1R")      # 光标位置查询
        if b"\x1b[c" in d: os.write(fd, b"\x1b[?62;c")       # 设备属性查询

        if b"\x1b]11;?" in d: os.write(fd, b"\x1b]11;rgb:0000/0000/0000\x1b\\")  # 背景色查询
        if b"\x1b[?u" in d: os.write(fd, b"\x1b[?0u")       # 键盘增强查询
pump(3)
for k in sys.argv[1:]:
    for ch in k.encode().decode("unicode_escape").encode(): os.write(fd, bytes([ch])); pump(0.05)
    pump(2)

if os.environ.get("RAW"): print(repr(buf[:1500]))

import unicodedata
R, C = 40, 110; scr = [[" "] * C for _ in range(R)]; y = x = 0
alt = buf.rfind(b"\x1b[?1049h"); data = buf[alt:] if alt >= 0 else buf
for m in re.finditer(rb"\x1b\[([0-9;?>]*)([A-Za-z@])|\x1b\][^\x07\x1b]*(?:\x07|\x1b\\)|\x1b[()][A-Z0-9]|\x1b[=>78]|([\r\n\b])|([^\x1b\r\n\b]+)", data):

    if cmd:
        ps = [int(v) if v.isdigit() else 0 for v in a.decode().lstrip("?>").split(";")] if a else []
        if cmd in b"Hf": y = (ps[0] if ps and ps[0] else 1) - 1; x = (ps[1] if len(ps) > 1 and ps[1] else 1) - 1

        elif cmd == b"G": x = (ps[0] if ps else 1) - 1

    elif ctl == b"\n": y = min(y + 1, R - 1)
    elif txt:

任务中按 /compact
写一个剧本让模型执行 sleep 5，在 TUI 中提交消息后立刻输入 /compact 回车。会发生什么？在源码中找到给出提示的位置。
查看参考答案
命令被拒绝，界面显示 '/compact' is disabled while a task is in progress.。这一检查在输入框层：bottom_pane/chat_composer.rs 的 reject_slash_command_if_unavailable（任务运行中且 available_during_task() 为 false 时拒绝；需要 requires_dispatch_validation 的命令如 /review 交给分派层）。分派层 slash_dispatch.rs L142 起还有一道同样的检查，覆盖回合正在启动、审阅模式等情况。用 tui.py 时按键序列可写成 "跑一下\r" "/compact\r"。

小结
记住这几点


  1. 定义：tui/src/slash_command.rs 的 enum SlashCommand（注释写着“DO NOT ALPHA-SORT! Enum order is presentation order”），strum 负责名字与别名（如 /pwd 别名 /cwd，/stop 别名 /clean）。
  2. 属性：description()；supports_inline_args()（如 /plan 文本、/goal 目标）；available_during_task()——/compact、/plan、/new 等在回合进行中被拒绝；available_in_side_conversation()。
  3. 可见性（bottom_pane/slash_commands.rs）：builtins_for_input 按特性开关过滤：没有协作模式就没有 /plan，没有 Goals 特性就没有 /goal，/apps、/plugins、/worktree 等同理。服务档位命令（如 /fast）是动态插入在 /model 之后的 ServiceTier 条目。
  4. 查找：find_builtin_command 先 from_str，还接受 /goooal 这种多个 o 的写法——仍解析为 /goal。
  5. 分派（chatwidget/slash_dispatch.rs）：/init = 提交 assets/prompt_for_init_command.md；/compact 设置状态栏后请求压缩；/plan 切换协作模式（下一课）。
  6. 与 exec 的关系：斜杠命令只存在于 TUI；codex exec "/init" 只会把字面量“/init”发给模型。
