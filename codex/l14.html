挑战
本地覆盖
在 repo 根目录再放一个 AGENTS.override.md（内容“覆盖规则”）。重新运行，根目录这一层用的是哪个文件？
查看参考答案
同一目录中 AGENTS.override.md 优先于 AGENTS.md（LOCAL_AGENTS_MD_FILENAME 被称为 “Preferred local override”），因此根目录这一层变成“覆盖规则”，“项目规则”不再出现；全局与 svc 层不受影响。适合放不想提交到仓库的个人规则。

小结
记住这几点


  1. 基础指令：来自模型元数据的 model_messages.instructions_template（gpt-5.5 以 “You are Codex, a coding agent based on GPT-5…” 开头，约 2 万字符）；本地未知模型回退到 models-manager/prompt.md。可用 model_instructions_file 替换。
  2. 第二条 developer 消息：developer_instructions（config.toml）、<skills_instructions>、<permissions instructions>（告诉模型当前沙箱与审批规则，以及如何请求提升）等。
  3. AGENTS.md 发现（core/src/agents_md.rs）：向上找到项目根（默认标记 .git，可配 project_root_markers），从根到 cwd 收集每一层的 AGENTS.md（本地覆盖文件 AGENTS.override.md 优先），按顺序拼接；不越过项目根。
  4. 全局与项目：$CODEX_HOME/AGENTS.md 在前，用分隔符 --- project-doc --- 与项目文档相连，整体包在 <INSTRUCTIONS> 中，作为一条 user 消息发送，标题 “# AGENTS.md instructions for <cwd>”。
  5. 大小上限：project_doc_max_bytes，默认 32 KiB。
  6. 环境上下文：<environment_context> 包含 cwd、shell 等；当它们在会话中变化时，Codex 会发送差异更新（world state），而不是重写整个提示。
