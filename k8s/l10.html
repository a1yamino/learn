在你的电脑上练习

给团队建一个有边界的命名空间。
01

创建命名空间，并把它设为当前 context 的默认值。

kubectl create namespace team-a
kubectl config set-context --current --namespace=team-a
kubectl config view --minify -o jsonpath="{..namespace}"
namespace/team-a created
Context "kind-learn" modified.
team-a
02

设置配额和默认值。

kubectl apply -f - <<'EOF'
apiVersion: v1
kind: ResourceQuota
metadata: { name: quota }
spec:
  hard: { requests.cpu: "1", requests.memory: 1Gi, limits.memory: 2Gi, pods: "10" }
---
apiVersion: v1
kind: LimitRange
metadata: { name: defaults }
spec:
  limits:
  - type: Container
    default: { cpu: 200m, memory: 256Mi }
    defaultRequest: { cpu: 100m, memory: 128Mi }
EOF
kubectl create deployment web --image=nginx:alpine --replicas=3
kubectl get pod -l app=web -o jsonpath="{.items[0].spec.containers[0].resources}"
{"limits":{"cpu":"200m","memory":"256Mi"},"requests":{"cpu":"100m","memory":"128Mi"}}

挑战

一行命令的排查报告

写一条（可以用管道的）命令：列出所有命名空间里重启次数大于 0 的容器，输出“命名空间/Pod/容器 重启次数”，按重启次数从大到小排序。提示：-o jsonpath 的 range。

查看参考答案
kubectl get pods -A -o jsonpath='{range .items[*]}{.metadata.namespace}{"/"}{.metadata.name}{" "}{range .status.containerStatuses[*]}{.name}{"="}{.restartCount}{" "}{end}{"\n"}{end}' \
 | awk '{for(i=2;i<=NF;i++){split($i,a,"=");if(a[2]>0)print a[2], $1"/"a[1]}}' | sort -rn
3 kube-system/kindnet-x7k2p/kindnet-cni
1 default/lv/lv

jsonpath 的 range 可以嵌套，但内层无法引用外层字段，所以先把每个 Pod 输出成一行（Pod 名 + 所有容器的“名=次数”），再交给 awk 拆开过滤。也可以用 -o json | jq：jq -r '.items[] | .metadata as $m | .status.containerStatuses[]? | select(.restartCount>0) | "\(.restartCount) \($m.namespace)/\($m.name)/\(.name)"' | sort -rn。

小结

记住这几点

  1. 命名空间划分名字和权限（RBAC、配额、网络策略都按命名空间配置）。它不隔离网络：不同命名空间的 Pod 默认可以互相访问（第 21 课）。
  2. ResourceQuota 限制整个命名空间的总量（CPU、内存、Pod 数、PVC 数…）；LimitRange 给没写 requests/limits 的容器设置默认值和上下限。
  3. 标签用来选择（Service、Deployment、查询），注解存放给工具看的元数据（变更原因、构建信息）。推荐标签：app.kubernetes.io/name、/instance、/version、/component、/part-of。
  4. 选择器：等值（app=web、env!=prod）和集合（env in (dev,staging)、!canary）。Deployment 的选择器创建后不能修改。
  5. kubectl 技巧：-o custom-columns、-o jsonpath、--field-selector、--sort-by、kubectl api-resources、kubectl auth can-i、别名和自动补全。
