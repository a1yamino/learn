挑战
写一个可靠的任务领取
在独立的 queue_jobs 表上实现任务队列（下面先给出完整结构）：多个 worker 并发领取，每个任务只被一个 worker 执行；worker 崩溃时任务不能永远卡在“处理中”。写出领取任务的 SQL，并说明锁的持有方式。
查看参考答案
CREATE TABLE queue_jobs (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  payload jsonb NOT NULL DEFAULT '{}',
  status text NOT NULL DEFAULT 'queued' CHECK (status IN ('queued', 'running', 'done')),
  locked_until timestamptz,
  worker text
);
CREATE INDEX ON queue_jobs (status, id);
-- 方案 A：在一个事务中领取并处理（任务短）
BEGIN;
SELECT id, payload FROM queue_jobs WHERE status = 'queued'
ORDER BY id LIMIT 1 FOR UPDATE SKIP LOCKED;
-- 处理……
UPDATE queue_jobs SET status = 'done' WHERE id = $1;
COMMIT;

-- 方案 B：领取后立即提交，用租约（任务长）
UPDATE queue_jobs SET status = 'running', locked_until = now() + interval '5 min', worker = $w
WHERE id = (SELECT id FROM queue_jobs
            WHERE status = 'queued' OR (status = 'running' AND locked_until < now())
            ORDER BY id LIMIT 1 FOR UPDATE SKIP LOCKED)
RETURNING id, payload;
方案 A：行锁随事务持有，worker 崩溃时连接断开、事务回滚，锁自动释放，任务回到可领取状态。缺点是处理期间一直占着一个事务，长任务会阻止 VACUUM，不适合超过几秒的任务。
方案 B：行锁只在领取的那条 UPDATE 中持有，之后靠 locked_until 租约；worker 定期续约，崩溃后租约过期，其他 worker 可以重新领取。需要任务本身幂等，因为租约过期时原 worker 可能仍在运行。为 (status, id) 建索引，并定期清理已完成的任务，否则队列表膨胀后领取会越来越慢。

小结
记住这几点


  1. 表级锁由语句自动获取：SELECT 拿 ACCESS SHARE；INSERT/UPDATE/DELETE 拿 ROW EXCLUSIVE；CREATE INDEX 拿 SHARE（阻塞写）；CREATE INDEX CONCURRENTLY、VACUUM 拿 SHARE UPDATE EXCLUSIVE；多数 ALTER TABLE、DROP、TRUNCATE、VACUUM FULL 拿 ACCESS EXCLUSIVE（与一切冲突，包括 SELECT）。
  2. 锁队列：锁请求按到达顺序排队。一个等待 ACCESS EXCLUSIVE 的 ALTER TABLE 排在长查询后面时，之后到达的所有 SELECT 都排在它后面——表看起来“锁死”。DDL 一定要设 lock_timeout（如 3s）并重试。
  3. 行锁记录在元组的 xmax 和 infomask 中，不占共享内存，所以锁一亿行也没问题。强度从弱到强：FOR KEY SHARE（外键检查用）、FOR SHARE、FOR NO KEY UPDATE（普通 UPDATE）、FOR UPDATE（DELETE 或修改主键/唯一键）。等待行锁时，会话等待的是持有它的事务 ID。
  4. SELECT … FOR UPDATE SKIP LOCKED 跳过已被锁的行，多个工作进程可以并发地从同一张表领取任务而互不等待。NOWAIT 拿不到锁立即报错。
  5. 死锁：T1 持有 A 等 B，T2 持有 B 等 A。等待超过 deadlock_timeout（1s）后检测，其中一个事务报 40P01 被回滚。预防：所有代码按相同顺序锁资源（例如按 id 排序后更新）；事务短小。
  6. 咨询锁 pg_advisory_lock(key) / pg_try_advisory_xact_lock(key)：由应用定义含义的锁，用于“同一时刻只能有一个实例跑这个定时任务”等场景。事务级版本在事务结束时自动释放，更安全。
