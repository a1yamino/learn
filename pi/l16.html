斜杠命令与提示模板

在 pi 的编辑器里输入 /，会出现四类命令：内置命令（/model、/tree、/compact……，由交互界面处理）、扩展命令、技能（/skill:name）和提示模板（Markdown 文件）。它们在不同的层被处理，顺序决定了谁能覆盖谁。本课还会加载 pi 官方示例中的 plan-mode 扩展：在 pi 里，“计划模式”不是内置功能，而是一个用工具切换实现的扩展。约 45 分钟。

export function substituteArgs(content: string, args: string[]): string {
  const allArgs = args.join(" ");

  return content.replace(
    /\$\{(\d+|ARGUMENTS|@):-([^}]*)\}|\$\{@:(\d+)(?::(\d+))?\}|\$(ARGUMENTS|@|\d+)/g,
    (_match, defaultTarget, defaultValue, sliceStart, sliceLength, simple) => {
      if (defaultTarget) {
        const value =
          defaultTarget === "@" || defaultTarget === "ARGUMENTS" ? allArgs : args[parseInt(defaultTarget, 10) - 1];
        return value ? value : defaultValue;
      }

      if (sliceStart) {
        let start = parseInt(sliceStart, 10) - 1; // Convert to 0-indexed (user provides 1-indexed)
        // Treat 0 as 1 (bash convention: args start at 1)
        if (start < 0) start = 0;

        if (sliceLength) {
          const length = parseInt(sliceLength, 10);
          return args.slice(start, start + length).join(" ");
        }
        return args.slice(start).join(" ");
      }

      if (simple === "ARGUMENTS" || simple === "@") {
        return allArgs;
      }

      const index = parseInt(simple, 10) - 1;
      return args[index] ?? "";
    },
  );
}
模板展开：
packages/coding-agent/src/core/prompt-templates.ts  L309–325 ↗
export function expandPromptTemplate(text: string, templates: PromptTemplate[]): string {
  if (!text.startsWith("/")) return text;

  const match = text.match(/^\/([^\s]+)(?:\s+([\s\S]*))?$/);
  if (!match) return text;

  const templateName = match[1];
  const argsString = match[2] ?? "";

  const template = templates.find((t) => t.name === templateName);
  if (template) {
    const args = parseCommandArgs(argsString);
    return substituteArgs(template.content, args);
  }

  return text;
}

小结
记住这几点


  1. 内置命令：定义在 core/slash-commands.ts（settings、model、tree、fork、clone、compact、resume、new、reload、login、export、share、trust……），由 interactive-mode.ts 的编辑器提交处理器逐一匹配。它们属于 UI 层，print/RPC 模式有各自的对应方式。
  2. 未被界面处理的输入进入 AgentSession.prompt：扩展命令 → input 事件 → /skill: 展开 → 提示模板展开（第 2 课的顺序）。不认识的 /xxx 原样作为文本发给模型。
  3. 提示模板：~/.pi/agent/prompts/*.md 或项目 .pi/prompts/*.md，文件名就是命令名；frontmatter 可写 description、argument-hint。参数按类 shell 规则解析（引号内的空格保留）。
  4. 占位符：$1、$2…；$@ / $ARGUMENTS（全部参数）；${1:-默认}；${@:N}、${@:N:L}（切片）。替换只做一层，参数中的 $1 不会被再次替换。
  5. 模板 vs 技能 vs 扩展命令：模板只是可复用的文字；技能是带资源文件、可被模型自主选用的说明书；扩展命令执行代码。
  6. 计划模式是扩展：示例 plan-mode 注册 /plan 命令和 --plan 标志，用 setActiveTools 去掉 edit/write、加入 grep/find/ls，并通过 tool_call 钩子只允许白名单内的只读 bash 命令；计划中的步骤从 “Plan:” 段落提取，执行时用 [DONE:n] 标记进度。
