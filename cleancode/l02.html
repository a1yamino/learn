有意义的命名

名字是代码里最多、也最便宜的文档。本课讲命名的几条核心规则：名副其实（名字回答“为什么存在、做什么、怎么用”），避免误导和无意义的区分，可读可搜索，不做心智映射，类名用名词、函数名用动词，每个概念只用一个词，用解决方案领域和问题领域的名字，添加有意义的上下文；以及名字长度与作用域的关系、Python 的命名惯例。练习会用重命名把一段“谜语代码”变得自解释。约 45 分钟。

02
第一步：只改名字，让每个名字回答“它是什么”。
cat > board.py <<'EOF'
STATUS_VALUE = 0
FLAGGED = 4

def get_flagged_cells(game_board):
    flagged_cells = []
    for cell in game_board:
        if cell[STATUS_VALUE] == FLAGGED:
            flagged_cells.append(cell)
    return flagged_cells

get_them = get_flagged_cells  # 旧名字，迁移期保留
EOF
python3 test_board.py

03
第二步：让“格子”成为一个类，is_flagged 隐藏了表示方式。
cat > board.py <<'EOF'
from dataclasses import dataclass

FLAGGED = 4

@dataclass
class Cell:
    status: int

    def is_flagged(self):
        return self.status == FLAGGED

def get_flagged_cells(game_board):
    return [cell for cell in game_board if cell.is_flagged()]
EOF
cat > test_board.py <<'EOF'
import unittest
from board import Cell, get_flagged_cells

class T(unittest.TestCase):
    def test_flagged(self):
        board = [Cell(0), Cell(4), Cell(2), Cell(4)]
        self.assertEqual(len(get_flagged_cells(board)), 2)

unittest.main(argv=["x"], exit=False, verbosity=0)
EOF
python3 test_board.py
----------------------------------------------------------------------
Ran 1 test in 0.000s

OK

def chk(u, b, d):
    if len(u.l) >= 5:
        return 1
    if b.s != "a":
        return 2

        return 3

查看参考答案
from enum import Enum

MAX_LOANS_PER_MEMBER = 5
MAX_LOAN_DAYS = 30
AVAILABLE = "a"

class LoanRefusal(Enum):
    NONE = 0
    TOO_MANY_LOANS = 1
    BOOK_NOT_AVAILABLE = 2
    PERIOD_TOO_LONG = 3

def check_loan_request(member, book, requested_days):
    if len(member.loans) >= MAX_LOANS_PER_MEMBER:
        return LoanRefusal.TOO_MANY_LOANS
    if book.status != AVAILABLE:
        return LoanRefusal.BOOK_NOT_AVAILABLE
    if requested_days > MAX_LOAN_DAYS:
        return LoanRefusal.PERIOD_TOO_LONG
    return LoanRefusal.NONE
返回码 1/2/3 也是名字的一种：用枚举给它们命名，调用方的 if result == 2 就变成 if result is LoanRefusal.BOOK_NOT_AVAILABLE。第 8 课会进一步讨论用异常代替返回码。

小结
记住这几点


  1. 名副其实：如果一个名字还需要注释来解释，它就不够好。d → elapsed_days；get_them() → flagged_cells()。
  2. 避免误导：不要叫 account_list 却是个字典；不要用只差一个字母的名字（XYZControllerForHandling 与 XYZControllerForStorage）；小写 l 和大写 O 容易看成 1 和 0。
  3. 有意义的区分：a1, a2、product_info 与 product_data、the_message 这类噪音词无法告诉读者区别在哪里。如果名字必须不同，那么意义也应不同。
  4. 可读、可搜索：能念出来的名字便于讨论；单字母名和魔法数无法搜索。名字长度应与作用域大小相称：3 行循环里的 i 可以接受，模块级常量要完整。
  5. 类名用名词，函数名用动词：Invoice、AddressParser；send_invoice()、is_overdue()。布尔值用 is_/has_/can_ 开头。一个概念一个词：不要同时用 fetch、retrieve、get 表示同一件事。
  6. 两种领域：程序员熟悉的概念用解决方案领域的名字（job_queue、visitor）；业务概念用问题领域的名字，与领域专家说同一种语言（领域驱动设计中的“通用语言”）。添加有意义的上下文：散落的 street, city, state 不如放进 Address。
