### 🐳 Docker 课程大纲
1. 为什么需要 Docker · 镜像与容器
2. 容器生命周期与核心命令
3. Dockerfile 入门与层缓存
4. 实战：把后端 API 打包成镜像
5. 多阶段构建与镜像瘦身
6. 数据卷与数据持久化
7. 网络与端口映射
8. Docker Compose：App + DB + Redis
9. 配置、环境变量与密钥
10. 镜像仓库、标签与推送
11. 调试与日志排障
12. 最佳实践、安全与走向生产

## 每一课都有 / What's in each lesson
- 可操作的图解：点击、拖动，观察每一步
- 模拟终端：点命令，看输出和解释
- 常见错误
- 自测题（即时判分）和小结
