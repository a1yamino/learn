挑战

前后端网络隔离

创建两个网络 front 和 back。db（redis）只在 back；api（alpine，sleep infinity）同时在两个网络；web（alpine）只在 front。证明 api 能访问 db，web 不能。

查看参考答案
docker network create front; docker network create back
docker run -d --name db --network back redis:7
docker run -d --name api --network back alpine sleep infinity
docker network connect front api
docker run -d --name web --network front alpine sleep infinity
docker exec api ping -c1 -W1 db | head -2
docker exec web ping -c1 -W1 db
PING db (172.21.0.2): 56 data bytes
64 bytes from 172.21.0.2: seq=0 ttl=64 time=0.1 ms
ping: bad address 'db'

docker network connect 把运行中的容器加入另一个网络，容器会多一块网卡。web 连名字都解析不出来，更访问不到 db。清理：docker rm -f db api web; docker network rm front back。

小结

记住这几点

  1. 每个容器有自己的网络命名空间：自己的网卡、IP 和 localhost。容器里的 localhost 是容器自己。
  2. 默认网络 bridge：容器接在宿主机的 docker0 网桥上，拿到 172.17.0.x 的地址。-p 通过 NAT 把宿主机端口转发到容器。
  3. 自定义网络自带 DNS：同一网络里的容器可以用容器名互相访问。默认 bridge 网络没有这个功能。
  4. 不同网络的容器默认互相不通。用多个网络隔离前端和数据库。
  5. -p 8080:80 对外开放；-p 127.0.0.1:8080:80 只允许本机访问。容器访问宿主机用 host.docker.internal（Linux 需加 --add-host=host.docker.internal:host-gateway）。
