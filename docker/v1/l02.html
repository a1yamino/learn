在你的电脑上练习

打开终端，按顺序执行。每一步都给出了预期输出，ID 和时间会不一样。
01

后台启动一个 nginx 容器，命名为 web，把本机 8080 端口映射到容器的 80 端口。

docker run -d --name web -p 8080:80 nginx:1.27
Unable to find image 'nginx:1.27' locally
1.27: Pulling from library/nginx
...
7c1f4a2e9b3d0c8e...（64 位容器 ID）
02

确认它在运行，然后用浏览器或 curl 访问。

docker ps
curl -s localhost:8080 | head -4
CONTAINER ID   IMAGE        STATUS         PORTS                  NAMES
7c1f4a2e9b3d   nginx:1.27   Up 5 seconds   0.0.0.0:8080->80/tcp   web
<!DOCTYPE html>
<html>
<head>
<title>Welcome to nginx!</title>
03

查看访问日志。刚才的 curl 请求应该出现在最后一行。

docker logs --tail 3 web
... "GET / HTTP/1.1" 200 615 "-" "curl/8.5.0" "-"
04

进入容器，修改首页，退出后再访问。

docker exec -it web sh -c 'echo hello > /usr/share/nginx/html/index.html'
curl -s localhost:8080
hello
05

停止再启动。修改还在吗？

docker stop web && docker start web && curl -s localhost:8080
web
web
hello

删除容器，再用同一个镜像新建一个。修改还在吗？

docker run -d --name web -p 8080:80 nginx:1.27

web

清理。

挑战

让容器自己重启

运行一个 5 秒后就退出的容器：docker run -d --name flaky alpine sh -c "sleep 5; exit 1"。不修改命令本身，让 Docker 在它退出后自动重启，并用一条命令看到它已经重启了几次。

查看参考答案
docker rm -f flaky
docker run -d --name flaky --restart on-failure:3 alpine sh -c "sleep 5; exit 1"
sleep 30; docker inspect -f '{{.RestartCount}} {{.State.Status}}' flaky
3 exited

--restart 有 no、on-failure[:N]、unless-stopped、always 四种。on-failure:3 只在非 0 退出时重启，最多 3 次。生产服务常用 unless-stopped。

小结

记住这几点

  1. 容器有五种状态：created、running、paused、exited，以及被删除。docker run = create + start。
  2. docker stop 先发配置的停止信号，未配置时为 SIGTERM；Linux 容器默认等待 10 秒，仍未退出才发 SIGKILL。镜像的 STOPSIGNAL 或运行时的 --stop-signal 可以覆盖信号；本课 nginx 使用 SIGQUIT。docker kill 默认直接发 SIGKILL。
  3. 停止的容器还在，可写层的数据也还在；docker rm 之后才真正删除。运行中的容器要先停止或用 rm -f。
  4. -d 后台运行；-it 分配终端并保持输入，用于交互式程序。
  5. docker logs 读容器主进程的 stdout/stderr；docker exec 在运行中的容器里再启动一个进程。
