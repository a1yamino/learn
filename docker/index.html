Docker

18 课，先建立原理，再走到交付与排障。每课按同一条路线展开：先想一想，读原理，看图解，猜结果，换场景，讲给面试官听。

  • 01快速上手
  • 01
    快速上手：交付一个 API
    先把一个小服务从源码送到可访问的端口，建立镜像、容器、端口三者的第一印象。
    →
  • 02–08进程、镜像与数据
  • 02
    容器本质与 namespace
    用“同一个进程，不同的视图”来理解隔离：PID、网络、挂载各自是一张独立的表。
    →
  • 03
    PID 1、信号与容器生命周期
    把容器对象、一次进程运行和数据分开看，弄清 docker stop 背后发生了什么。
    →
  • 04
    cgroups 与资源诊断
    把“给多少”和“用了多少”分开，区分 CPU 节流、内存回收和 OOM。
    →
  • 05
    一次 docker run 背后的运行链路
    把 CLI、dockerd、containerd、runc 和内核串成一条线，知道每一段负责什么。
    →
  • 06
    OCI 镜像：层、配置与内容身份
    分清标签、摘要和镜像 ID，明白为什么同一个名字不保证同一份内容。
    →
  • 07
    OverlayFS、挂载与容器文件视图
    容器看到的根目录是几层只读层加一层可写层合起来的，挂载会盖在上面。
    →
  • 08
    数据生命周期、权限与可验证恢复
    让数据活得比容器久，并且能证明备份真的能恢复。
    →
  • 09–12网络与构建
  • 09
    网络空间：bridge、veth 与服务发现
    沿着一次容器间连接，看清网卡、网桥和服务名解析各在做什么。
    →
  • 10
    NAT、防火墙与回程：一个包的完整路径
    端口发布靠目的地址改写，出站靠源地址伪装，两边都依赖连接跟踪。
    →
  • 11
    构建上下文、依赖图与缓存正确性
    从输入推断哪些步骤会重建，让缓存既快又不出错。
    →
  • 12
    多平台与可复现构建：固定的究竟是什么
    区分平台索引和单平台清单，弄清“可移植”“可重部署”“可复现”各自要固定什么。
    →
  • 13–15编排与安全边界
  • 13
    Compose：期望状态、就绪与运行中恢复
    分清“已启动”“已健康”“能恢复”，让一次 up 之后的系统也站得稳。
    →
  • 14
    运行时安全边界：身份、能力与系统调用
    按威胁来理解每一层防护：非 root、capabilities、seccomp、只读根目录和 rootless。
    →
  • 15
    供应链证据：扫描、SBOM 与身份验证
    分清“里面有什么”“有没有漏洞”“是谁构建的”，让放行和拒绝都说得出理由。
    →
  • 16–18交付、排障与毕业
  • 16
    可验证发布：让证据跟随最终运行产物
    一次发布从构建到上线，每一步都留下与摘要绑定的证据。
    →
  • 17
    未知故障诊断：从症状到可证伪的根因
    面对一个 502，按层取最小证据，每一步都排除一类原因。
    →
  • 18
    综合项目与面试毕业验收
    把前面 17 课串成一次完整推演：交付、恢复、排障，再用面试题检验能否讲清楚。
    →
