DOCKER · 原理与实战

从会运行，到能解释

18 课主线，从一个可运行的 API 出发，理解进程、文件、网络与构建；用独立交付和 Docker 专项面试共同验收。

怎样使用这门课

每课先建立模型、写下预测，再执行实验。遇到不同结果，记录证据并修正解释。最后用陌生场景和连续追问检查能否独立迁移。

实验代码位于 docker/labs，已提供 API、数据库与反向代理。页面图解不会操作 Docker。Linux 专属命令、权限和环境前提会在课内标明。

目录完成状态来自你在本机勾选的实操和面试记录，不是自动评分。

  • 快速上手
  • 01
    快速上手：交付一个 API
    先完成一次最小闭环，再带着真实现象学习进程、存储、网络和构建原理。
    待学习→
  • 进程、镜像与数据
  • 02
    容器本质与 namespace
    用同一进程的不同视图解释 PID、localhost 和挂载隔离，并辨认 Docker Desktop 中真正的 Linux 执行环境。
    待学习→
  • 03
    PID 1、信号与容器生命周期
    把进程退出、容器状态和数据生命周期分开，用正在进行的请求证明优雅退出。
    待学习→
  • 04
    cgroups 与资源诊断
    从预算、使用量和内核事件区分 CPU 节流、内存回收与 OOM，把调参建立在可验证证据上。
    待学习→
  • 05
    一次 docker run 背后的运行链路
    把 CLI、Engine、containerd、OCI runtime 与内核进程串起来，解释 create、start、exec 的不同边界。
    待学习→
  • 06
    OCI 镜像：层、配置与内容身份
    分清标签、仓库摘要、镜像 ID 和层 diffID，解释为什么同名不保证同内容。
    待学习→
  • 07
    OverlayFS、挂载与容器文件视图
    用新增、删除和挂载遮蔽三个观察，分清镜像层、容器可写层与外部存储。
    待学习→
  • 08
    数据生命周期、权限与可验证恢复
    从订单写入到卷备份、删除与恢复，证明数据能跨容器重建且应用仍有正确权限。
    待学习→
  • 网络与构建
  • 09
    网络空间：bridge、veth 与服务发现
    沿着一次连接解释 localhost、容器网卡、共享网桥和服务名解析，并区分名字可解析与服务可连接。
    待学习→
  • 10
    NAT、防火墙与回程：一个包的完整路径
    解释端口发布的目的地址改写、转发过滤、出站伪装与连接跟踪，并辨认本机请求和外部请求的路径差异。
    待学习→
  • 11
    构建上下文、依赖图与缓存正确性
    从构建输入和依赖关系预测哪些步骤会重建，区分镜像层缓存、缓存挂载与真正的发布测试。
    待学习→
  • 12
    多平台与可复现构建：固定的究竟是什么
    分清平台索引、单平台清单、运行配置和文件层，用实际 digest 与重复构建证据解释可移植、可重部署和可复现。
    待学习→
  • 编排与安全边界
  • 13
    Compose：期望状态、就绪与运行中恢复
    分清创建依赖、健康状态、进程重启和应用重连，理解一次 up 成功之后系统还需要什么恢复能力。
    待学习→
  • 14
    运行时安全边界：身份、能力与系统调用
    用威胁与可观察权限解释非root、capabilities、seccomp、只读挂载和rootless，避免把安全参数当成相同的防护层。
    待学习→
  • 15
    供应链证据：扫描、SBOM与身份验证
    把软件清单、漏洞判断、内容摘要和签名身份拆开，建立能够解释通过与拒绝原因的发布证据。
    待学习→
  • 交付、排障与面试
  • 16
    可验证发布：让证据跟随最终运行产物
    先完成无需云账号的单平台构建、业务验证、内容固定和重新部署，再扩展到仓库摘要、身份验证与多平台发布。
    待学习→
  • 17
    未知故障诊断：从症状到可证伪的根因
    面对同一个502或未就绪症状，按DNS、TCP、应用、挂载和资源取得最小证据，修复后证明业务与数据恢复。
    待学习→
  • 18
    综合项目与面试毕业验收
    用独立交付、恢复、未知故障和 Docker 专项面试，证明原理已经转化成可用能力。
    待学习→
毕业标准

实战与面试，都有证据
