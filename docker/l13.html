在你的电脑上练习

前半部分需要 Linux（Mac / Windows：在 docker run --rm -it --privileged ubuntu:24.04 里做）。后半部分任何平台都可以。
01

手动创建一个 overlay。

mkdir -p /tmp/ov/{lower,upper,work,merged} && cd /tmp/ov
echo base > lower/a.txt; echo keep > lower/b.txt
sudo mount -t overlay overlay -o lowerdir=lower,upperdir=upper,workdir=work merged
ls merged
a.txt  b.txt
02

修改 a.txt：它被复制到 upper，lower 不变。

echo changed | sudo tee merged/a.txt >/dev/null
cat lower/a.txt upper/a.txt
base
changed
03

删除 b.txt：upper 里出现一个 whiteout。

sudo rm merged/b.txt
ls merged; ls -l upper/b.txt
a.txt
c--------- 1 root root 0, 0 Oct 21 18:30 upper/b.txt
04

卸载。lower 完好如初。

sudo umount merged; cat lower/b.txt
keep

挑战

不运行容器，找出文件来自哪一层

对 python:3.12-slim 执行 docker save，找出 /usr/local/bin/python3.12 是在哪一层加入的，并且只把这个文件从那一层里解压出来。

查看参考答案
mkdir /tmp/py && cd /tmp/py && docker save python:3.12-slim | tar -x
M=$(python3 -c "import json;print(json.load(open('index.json'))['manifests'][0]['digest'][7:])")
for L in $(python3 -c "import json;[print(l['digest'][7:]) for l in json.load(open('blobs/sha256/$M'))['layers']]"); do
  tar -tf blobs/sha256/$L 2>/dev/null | grep -qx "usr/local/bin/python3.12" && echo "found in $L"
done
tar -xf blobs/sha256/<上面找到的哈希> usr/local/bin/python3.12 && ls -lh usr/local/bin/python3.12
found in 6c8f2a1e…
-rwxr-xr-x 1 you you 15K Oct  9 usr/local/bin/python3.12

每一层就是一个普通的 tar 包（可能经过 gzip/zstd 压缩，用 tar -tzf）。这也是第 9 课里“删除的文件仍然能拿到”的原理。dive 这个工具可以交互式地浏览每一层。

小结

记住这几点

  1. OverlayFS 把多个只读的 lowerdir（镜像层）和一个可写的 upperdir（容器层）叠加成一个 merged 视图。
  2. 读文件：从上往下找，第一个找到的生效。改文件：先把整个文件从下层复制到上层（copy-up）再修改。删文件：在上层创建一个whiteout（字符设备 0/0）遮住下层。
  3. copy-up 以整个文件为单位：修改一个 1GB 文件的一个字节，也要先复制 1GB。频繁写的数据放在数据卷里。
  4. OCI 镜像 = index（多平台列表）→ manifest（一个平台）→ config（运行配置）+ layers（tar 压缩包）。每一项都用内容的 sha256 寻址。
  5. 因为按内容寻址，相同的层在磁盘和仓库里只存一份，可以被任意多个镜像共享。
