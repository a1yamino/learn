在你的电脑上练习

一个带健康检查、迁移任务和可选管理面板的应用。
01

创建项目。

mkdir cdeep && cd cdeep
cat > compose.yaml <<'EOF'
services:
  db:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: ${DB_PASSWORD:?set DB_PASSWORD}
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 2s
      retries: 15
  migrate:
    image: postgres:16
    command: psql -h db -U postgres -c "CREATE TABLE IF NOT EXISTS t(id int)"
    environment:
      PGPASSWORD: ${DB_PASSWORD}
    depends_on:
      db: { condition: service_healthy }
  web:
    image: nginx:alpine
    ports: ["${WEB_PORT:-8080}:80"]
    depends_on:
      migrate: { condition: service_completed_successfully }
  adminer:
    image: adminer
    ports: ["8081:8080"]
    profiles: [debug]
EOF
docker compose config >/dev/null
error while interpolating services.db.environment.POSTGRES_PASSWORD: required variable DB_PASSWORD is missing a value: set DB_PASSWORD

挑战

生产覆盖文件

新增 compose.prod.yaml：web 改为 80 端口、设置 restart: unless-stopped、限制 web 内存 128M，db 加一个命名卷。用 -f 合并后查看结果，确认 web 的内存限制生效。

查看参考答案
cat > compose.prod.yaml <<'EOF'
services:
  web:
    ports: !override ["80:80"]
    restart: unless-stopped
    deploy:
      resources:
        limits: { memory: 128M }
  db:
    restart: unless-stopped
    volumes: [pgdata:/var/lib/postgresql/data]
volumes:
  pgdata:
EOF
docker compose -f compose.yaml -f compose.prod.yaml config | grep -A3 "limits"
docker compose -f compose.yaml -f compose.prod.yaml up -d
docker inspect cdeep-web-1 -f "{{.HostConfig.Memory}}"
          memory: "134217728"
134217728

列表类字段（ports）默认是追加合并，所以用 !override 替换而不是同时映射 8080 和 80。标量字段（restart）直接覆盖。也可以设置 COMPOSE_FILE=compose.yaml:compose.prod.yaml，省去每次写 -f。

小结

记住这几点

  1. depends_on 默认只等容器启动，不等服务就绪。配合 healthcheck 用 condition: service_healthy。
  2. 一次性任务（数据库迁移）用 condition: service_completed_successfully，主服务在它成功退出后才启动。
  3. profiles 让调试工具、管理面板等服务默认不启动，--profile debug 时才启动。
  4. 多文件：compose.yaml 放公共部分，compose.override.yaml 自动叠加（开发），-f compose.yaml -f compose.prod.yaml 用于生产。docker compose config 查看合并结果。
  5. 变量插值：${TAG:-latest} 提供默认值，${DB_PASSWORD:?缺少密码} 缺失时直接报错。值来自 shell 环境和 .env 文件。
  6. develop.watch：改代码自动同步进容器，改依赖文件自动重建。
